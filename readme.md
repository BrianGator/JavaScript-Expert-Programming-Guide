The **JavaScript Expert Programming Guide** is a structured JavaScript learning repository organized by programming subject matter, interview preparation, browser programming, frontend projects, asynchronous JavaScript, object-oriented programming, tooling, testing, Node.js, REST APIs, and full-stack JavaScript development.

# JavaScript Programming Tutorial with Code Samples

## Variables and Data Types

```javascript
const firstName = 'Brian';
let yearsExperience = 5;
const isLearning = true;

console.log(typeof firstName); // string
console.log(typeof yearsExperience); // number
console.log(typeof isLearning); // boolean
```

Variables store values that the program can use later. Use `const` by default and `let` when reassignment is required.

## Arrays and Objects

```javascript
const skills = ['JavaScript', 'Node.js', 'REST APIs'];

const developer = {
  name: 'Brian McCarthy',
  role: 'JavaScript Developer',
  skills
};

console.log(developer.skills[0]);
```

Arrays store ordered lists. Objects store named properties and are commonly used to represent real-world entities.

## Functions and Scope

```javascript
function calculateTotal(price, quantity) {
  return price * quantity;
}

const total = calculateTotal(25, 4);
console.log(total); // 100
```

Functions group reusable logic. Scope controls where variables can be accessed.

## Control Flow

```javascript
const score = 85;

if (score >= 90) {
  console.log('Excellent');
} else if (score >= 70) {
  console.log('Passed');
} else {
  console.log('Needs improvement');
}
```

Control flow lets JavaScript make decisions based on conditions.

## Array Methods

```javascript
const numbers = [1, 2, 3, 4, 5];
const doubled = numbers.map(number => number * 2);
const even = numbers.filter(number => number % 2 === 0);

console.log(doubled);
console.log(even);
```

Array methods such as `map`, `filter`, and `reduce` are essential for transforming and analyzing data.

## DOM Manipulation

```javascript
const title = document.querySelector('h1');
title.textContent = 'JavaScript Tutorial';
title.classList.add('active');
```

The DOM allows JavaScript to update HTML elements dynamically in the browser.

## Events

```javascript
const button = document.querySelector('#save-button');

button.addEventListener('click', () => {
  console.log('Button clicked');
});
```

Events connect JavaScript logic to user actions such as clicks, typing, and form submissions.

## Async JavaScript and Fetch

```javascript
async function loadUsers() {
  try {
    const response = await fetch('/api/users');
    const users = await response.json();
    console.log(users);
  } catch (error) {
    console.error('Failed to load users:', error);
  }
}
```

Asynchronous JavaScript handles delayed work such as API calls without blocking the application.

## Object-Oriented JavaScript

```javascript
class User {
  constructor(name, role) {
    this.name = name;
    this.role = role;
  }

  describe() {
    return `${this.name} is a ${this.role}.`;
  }
}

const user = new User('Brian', 'Developer');
console.log(user.describe());
```

Classes organize related data and behavior into reusable objects.

## Modules

```javascript
// math.js
export function add(a, b) {
  return a + b;
}

// app.js
import { add } from './math.js';
console.log(add(2, 3));
```

Modules split code into reusable files and make larger applications easier to maintain.

## Testing and Algorithms

```javascript
function reverseString(value) {
  return value.split('').reverse().join('');
}

console.assert(reverseString('JavaScript') === 'tpircSavaJ');
```

Testing confirms that functions return expected results. Algorithm practice strengthens problem-solving skills.

## Node.js and REST APIs

```javascript
const express = require('express');
const app = express();

app.use(express.json());

app.get('/api/health', (req, res) => {
  res.json({ status: 'ok' });
});

app.listen(3000, () => console.log('Server running on port 3000'));
```

Node.js allows JavaScript to run on the server. REST APIs expose data and application behavior through HTTP endpoints.
